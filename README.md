# FlytBase Mining Outbound Automation

## Overview
An AI-assisted outbound prospecting system targeting mining operators across Latin America.

## Workflow
1. ICP-based account selection
2. Account research and source retrieval
3. Evidence validation using Gemini
4. Contact qualification
5. Personalized email generation
6. Independent AI email review
7. Human approval
8. Gmail draft creation

## Technology
- Google Sheets
- Google Apps Script
- Gemini API
- Gmail

## Sheets
Config, Accounts, Contacts, Research, Outreach, QA, Run_Log, Dashboard.

## Approval Process
Emails require human approval before Gmail draft creation. The system does not automatically send emails.

## Limitations
Research quality depends on publicly available sources. Unverified operational assumptions are treated as discovery questions.
